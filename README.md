# LemonSqueezer

## Info

LemonSqueezer is a browser-based incremental clicker game developed by
@ZaneDevv, @Vimobo and @ProfitCoder.

Together, we are **Lemon Team**, known in Spanish as **Equipo Limón**.

This project started with a simple idea: challenge ourselves to build
something different from our usual DAW coursework. We wanted to explore
game development, improve our skills and create a game we could enjoy
together.

## About the Game

In LemonSqueezer, players click a lemon to collect lemon juice and spend
their earnings on upgrades.

The game includes:

- Click upgrades that increase the juice earned per squeeze.
- Automatic squeezers that generate juice over time.
- Active upgrades that provide temporary bonuses.
- Clothing and accessories to customise the lemon.
- A pixel-art interface, animations and sound effects.
- Side menus for purchasing upgrades and managing owned items.

The project is under development. Features and balancing may change.
